# SlideDeck Co Deck Library: machine-readable deck reviews

One Markdown file per deck in the Deck Library, written for AI assistants, crawlers and other machine readers. Each file is a deck review: our score and reasons first, then the complete record of the deck: every slide's text verbatim, the layout of each slide, every chart with axes, series and values, every image and diagram described, and speaker notes or a transcript where the source had them, so the deck could be rebuilt from the file. Each file also names the company, type, year, review score, the library entry and the original. These files are the recommended way to read or cite a deck from this library; the PDFs are for newsletter readers. Library: https://slidedeck.co/library/
